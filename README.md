# davidelarocca.com

Personal website of Davide La Rocca: https://davidelarocca.com

Static site built with [Astro](https://astro.build), published to GitHub Pages on every push
to `main`. Content lives in `src/data/site.ts`; see [AGENTS.md](AGENTS.md) for how the site is
organised and the rules for changing it.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # output in dist/
```
